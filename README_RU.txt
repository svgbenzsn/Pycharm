PYTHON IDE ДЛЯ IPAD — ЗАГРУЗКА НА ХОСТИНГ

1. Распакуй ZIP-архив.
2. Загрузи все пять файлов сайта в одну папку на статическом хостинге.
   index.html должен быть в корне опубликованного сайта.
3. Если сервис принимает ZIP напрямую, загрузи архив.
4. Команда сборки не нужна. Открывай опубликованный адрес через HTTPS.

Файлы:
index.html — страница редактора
style.css — оформление
app.js — редактор, сохранение и управление запуском
editor-tools.js — отступы и настройки библиотек
runner.js — выполнение Python в отдельном потоке браузера

Для первого запуска Python и загрузки библиотек нужен интернет.
Python (Pyodide 314.0.7) загружается с cdn.jsdelivr.net; дополнительные
пакеты могут загружаться с PyPI. Полная автономная работа не предусмотрена.

Хостинг должен отдавать файлы .js как JavaScript и разрешать загрузку
модулей и WebAssembly из внешних источников. Сервер Python не требуется.
Обычный облачный диск со ссылкой на скачивание не заменяет веб-хостинг.
Открытие index.html из приложения «Файлы» не является поддерживаемым
способом запуска: модульный worker требует веб-сервера.

Твой код сохраняется в браузере на конкретном устройстве и адресе сайта.
Скрипты, набранные на прежнем сайте, в этот архив не входят и автоматически
на новый адрес не переносятся. Скачай их кнопкой «Скачать .py» на прежнем сайте.
На новом сайте нажми «Загрузить файлы» и выбери сохранённые файлы.

Enter после for/if/def и двоеточия добавляет 4 пробела к текущему отступу.
Вложенные блоки получают 8, 12 и далее пробелов.
Библиотеки настраиваются кнопкой «Библиотеки».
Данные для input() вводятся заранее, по одной строке на каждый вызов.

Архив содержит исходники редактора без ключей доступа и настроек прежнего хостинга.


ЗАГРУЗКА С IPAD
Нажми «Загрузить файлы» в панели проекта и выбери файлы в приложении «Файлы».
Поддерживаются .py, .txt, .csv, .json и .tsv в UTF-8.
До 1 МБ на файл, суммарно до 2 МБ и до 100 файлов в проекте.
При совпадении имени появится запрос на замену.
Открой Python-файл и читай данные по имени, например:
with open("17.txt", encoding="utf-8") as f:
    numbers = [int(line) for line in f]
print(numbers)
Загруженные файлы сохраняются в браузере на этом устройстве.
